# iPhone Duo pull request screenshots

Image-only artifacts for the iPhone Duo app adaptation. Hosted separately from the implementation branch so screenshots are not part of the pull request diff.

- before-sign-in.png: earlier card-based sign-in layout captured during development, before the final visual refinement. This is not a pristine main-branch baseline.
- after-sign-in.png: final card-free sign-in layout.
- after-previews.png, after-preview-detail.png, after-profile.png, after-profile-actions.png: real signed-in demo account screens. No destructive action was executed.
- overview.png: scaled, uncropped overview of the final screens.

Captured on the existing Tuist iPhone Duo simulator, iOS 27.2, with Xcode 27.2. All screenshots show the active outer display. Opened, partially folded, and inner-display landscape layouts remain unverified.
